5.1 · C++

从 C 到 C++：更省事的输入输出

C++ 兼容 C，所以你会的一切依然有效；它新增的语法让代码更短、更不容易出错。

1. cin / cout

程序 5-2 · 读两个整数输出和C++
#include <iostream>
using namespace std;

int main() {
  int a, b;
  cin >> a >> b;          /* 自动识别类型，不用写 %d */
  cout << a + b << endl;   /* endl 表示换行 */
  return 0;
}

cin 自动跳过空白、自动按类型读，不用记 %d %f，也不用写 &（string、数组名直接写）。读多组数据直到 EOF 的写法是 while (cin >> a >> b)。

2. 引用：变量的别名

程序 5-3 · 引用交换C++
void swap(int &x, int &y) {   /* x、y 是 a、b 的别名 */
  int t = x; x = y; y = t;
}

int main() {
  int a = 3, b = 5;
  swap(a, b);                /* 不用写 & 了 */
  cout << a << " " << b << endl;   /* 5 3 */
  return 0;
}

3. string：会 + 会 == 的字符串

程序 5-4 · string 基础C++
#include <iostream>
#include <string>
using namespace std;

int main() {
  string s = "acm", t = "icpc";
  cout << s + t << endl;        /* 拼接：acmicpc */
  cout << s.length() << endl;   /* 长度：3 */
  cout << (s == "acm") << endl; /* 相等比较：1 */
  return 0;
}

5.2 · STL

STL 初步：四大金刚

STL 是 C++ 自带的「工具箱」。先记住每个工具解决什么问题。

1. vector：会自己长大的数组

程序 5-5 · vector 基本用法C++
#include <iostream>
#include <vector>
using namespace std;

int main() {
  vector<int> v;
  v.push_back(5); v.push_back(3);   /* 末尾追加 */
  v.push_back(8);
  cout << v.size() << endl;         /* 3 */
  cout << v[0] << " " << v[2] << endl;  /* 5 8，下标从 0 开始 */
  return 0;
}

2. set：去重 + 有序

set<int> s; 自动去重并按从小到大排序；s.insert(x) 插入，s.count(x) 判断在不在。

程序 5-6 · set 去重排序C++
#include <iostream>
#include <set>
using namespace std;

int main() {
  set<int> s;
  s.insert(5); s.insert(3); s.insert(8);
  s.insert(3);                  /* 重复，被忽略 */
  for (int x : s) cout << x << " ";   /* 3 5 8 */
  cout << endl;
  return 0;
}

3. map：键值映射

map<string,int> m; 像字典：m["apple"] = 3; 存，m["apple"] 取。常用在「统计词频」「按名字查分数」。

程序 5-7 · map 统计词频C++
#include <iostream>
#include <map>
using namespace std;

int main() {
  map<string, int> cnt;
  cnt["acm"]++;
  cnt["icpc"]++;
  cnt["acm"]++;                 /* 现在是 2 */
  cout << cnt["acm"] << endl;   /* 2 */
  return 0;
}

4. sort：排序就一行

sort 底层是快速排序的改进，时间复杂度 $O(n \log n)$，n=10⁶ 也能轻松搞定——这也是很多题目「排序后就好做」的原因。

程序 5-8 · sort 排序C++
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
  int a[] = {5, 3, 8, 1, 9};
  int n = 5;
  sort(a, a + n);                    /* 从小到大 */
  for (int i = 0; i < n; i++) cout << a[i] << " ";   /* 1 3 5 8 9 */
  cout << endl;
  return 0;
}

5.4 · CONTEST

竞赛题目举例：去重排序

用一道原创题把 sort、set、vector 串起来，感受 STL 的威力。

例题（原创重述）：去重后从小到大输出

输入 n 个整数，去掉重复的，把剩下的从小到大输出。

思路一（set）：全部丢进 set，自动去重 + 有序，遍历输出即可。思路二（sort + 手动去重）：先 sort，再跳过连续相同的。

程序 5-9 · set 一行去重C++
#include <iostream>
#include <set>
using namespace std;

int main() {
  int n, x;
  cin >> n;
  set<int> s;
  while (n--) { cin >> x; s.insert(x); }
  for (int v : s) cout << v << " ";
  cout << endl;
  return 0;
}

如果还要求「按输入顺序输出第一个出现的」，那就用 vector + set 配合：set 负责查重，vector 负责保序——这是竞赛里的经典组合。

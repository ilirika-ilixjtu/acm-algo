1.1 · EXPRESSION

算术表达式：从「算数」开始

计算机的看家本领是计算。这一节我们把「怎么算、怎么输出」彻底搞明白。

1. 用 C 写算术

在 C 语言里，加减乘除分别写成 + - * /，另外还有一个取余运算符 %（求整除后的余数）。键盘上没有乘号「×」和除号「÷」，所以用星号和斜杠代替：5*6、8/4。

最容易踩的坑：整数除法。当两个操作数都是整数（int）时，/ 做的是整数除法——直接丢掉小数部分。所以 8/5 的结果是 1，不是 1.6；(-8)/5 的结果是 -1。

想得到小数结果，只要让操作数里出现一个浮点数（double）就行：8.0/5.0 等于 1.6。下面两个程序对比了这两种写法。

2. 两个对照程序

程序 1-1 · 计算并输出 1+2C
#include <stdio.h>

int main() {
  printf("%d\n", 1 + 2);   /* %d 表示这里输出一个整数 */
  return 0;
}

运行结果：屏幕上出现 3。%d 是「格式占位符」，告诉 printf 把后面的整数填到这个位置；\n 表示换行。

程序 1-2 · 输出 8.0/5.0，保留 1 位小数C
#include <stdio.h>

int main() {
  printf("%.1f\n", 8.0 / 5.0);  /* %.1f 输出浮点数，保留 1 位小数 */
  return 0;
}

运行结果：1.6。注意 %.1f 里的小数点和数字 1 一个都不能少，%f 专门用来输出浮点数。

1.2 · VARIABLE

变量及其输入：给数据起名字

程序不只是算固定数，还要能「读入用户给的数据」再处理。这一节学变量、scanf 和三变量交换。

1. 变量就是「有名字的盒子」

变量是一块内存的名字。声明 int a; 就是向系统申请一个能装整数的盒子，并叫它 a；之后 a = 3; 把 3 放进盒子。常见的两种类型：int 装整数，double 装小数（浮点数）。

程序 1-3 · 读入两个整数，输出它们的和C
#include <stdio.h>

int main() {
  int a, b;
  scanf("%d%d", &a, &b);   /* 从键盘读入两个整数 */
  printf("%d\n", a + b);    /* 输出它们的和 */
  return 0;
}

& 是重点：scanf 要把读到的数据「放回」变量里，所以必须写 &a（取 a 的地址）。这是新手最常见的坑之一——漏掉 & 程序会在运行时崩溃或读到垃圾值。

2. 三变量交换

交换两个变量的值，需要第三只手。就像要把两杯饮料互换，得先拿一个空杯子：

程序 1-4 · 三变量交换C
#include <stdio.h>

int main() {
  int a = 3, b = 5, t;
  t = a;   /* t 保存 a 的副本 */
  a = b;   /* a 拿走 b 的值 */
  b = t;   /* b 拿到原来 a 的值 */
  printf("%d %d\n", a, b);   /* 输出 5 3 */
  return 0;
}
1初始：a=3，b=5。先让空杯子 t 接住 a：t=a，此时 t=3，a、b 不变。
2把 b 倒进 a：a=b，此时 a=5，b=5，t=3。
3把 t 里保存的原 a 倒给 b：b=t，此时 a=5，b=3，t=3。
4交换完成：a=5，b=3。程序输出 5 3。

!浮点数的隐藏陷阱

浮点数在计算机里是近似存储的，比如 $0.1 + 0.2 \neq 0.3$，并不精确相等。因此判断两个浮点数是否相等不要用 ==，而是看它们的差是否足够小（比如小于 0.000001）。这一章先记住这个结论，第 8 章学算法分析时还会遇到。

1.3 · SEQUENCE

顺序结构：程序是「按步骤」跑起来的

顺序结构最简单也最容易被轻视：程序从 main 的第一条语句开始，一条一条往下执行。

1. 顺序执行

「顺序」的意思是：除非遇到 if、循环等控制语句，否则程序严格从上到下、逐条执行。写程序时，把任务拆成有序的小步骤，每步对应一条语句——这就是顺序结构程序设计。

2. 经典例题：三位数反转

题目（自己重新表述的版本）：读入一个三位数，输出它的「倒序」。例如读入 123，输出 321；读入 900，输出 9（前导 0 不显示）。

拆解步骤：一个三位数 n 的百位是 n/100，十位是 n/10%10，个位是 n%10。把个位、十位、百位依次输出，就是倒序。

程序 1-5 · 三位数反转C
#include <stdio.h>

int main() {
  int n, a, b, c;
  scanf("%d", &n);        /* 读入三位数，比如 123 */
  a = n / 100;            /* a = 1，百位 */
  b = n / 10 % 10;        /* b = 2，十位 */
  c = n % 10;             /* c = 3，个位 */
  printf("%d%d%d\n", c, b, a);  /* 输出 321 */
  return 0;
}

1.4 · BRANCH

分支结构：让程序「看情况」做事

有了分支，程序不再是一条道走到黑，而是根据条件选择不同的路。

1. if / else 的骨架

程序 1-6 · 判断奇偶C
#include <stdio.h>

int main() {
  int x;
  scanf("%d", &x);
  if (x % 2 == 1)          /* 余数为 1 说明是奇数 */
    printf("ODD\n");       /* 条件成立走这里 */
  else
    printf("EVEN\n");      /* 否则走这里 */
  return 0;
}

判断的依据是条件表达式：x % 2 == 1 的值为「真」或「假」。C 语言里，非 0 代表真，0 代表假。常用的关系运算符：==（等于）、!=（不等于）、>、<、>=、<=。

2. 多分支：else if

程序 1-7 · 成绩等级C
#include <stdio.h>

int main() {
  int score;
  scanf("%d", &score);
  if (score >= 90)       printf("A\n");
  else if (score >= 80)  printf("B\n");
  else if (score >= 70)  printf("C\n");
  else if (score >= 60)  printf("D\n");
  else                   printf("E\n");
  return 0;
}

程序从上往下依次检查：满足哪个条件就执行对应的输出，然后整个 if-else 链结束。注意判断顺序很重要——比如 95 分先撞上 >=90，输出 A，就不会再去检查后面的条件。

3. 可视化：判断流程

▶奇偶判断流程
小测｜分支输出if/else

运行下面代码，输出是：

int x = 7;

  printf("ODD");

  printf("EVEN");
/* 只有一种情况要处理 */
if (条件) { 语句; }

/* 二选一 */
if (条件) { 情况A; } else { 情况B; }

/* 多分支 */
if (条件1) { ...; }
else if (条件2) { ...; }
else { ...; }

单条语句可以省略花括号，但建议初学者永远带上花括号，能避免很多隐蔽的 bug。

⚠最经典的坑：= 与 ==

= 是赋值，== 才是比较。写 if (x = 5) 会把 5 赋给 x，然后因为 5 非 0 而永远「成立」——编译器往往不报错，逻辑却全错了。判断相等时，可以习惯性地把常量写在左边：if (5 == x)，这样万一写错成 5 = x 编译器会立刻报错。

程序 7-1 · 枚举 1~n 的全排列C++
int a[10], n;
void dfs(int cur) {        /* cur: 已经填了几个位置 */
  if (cur == n) { for (int i = 0; i < n; i++) cout << a[i] << " "; cout << endl; return; }
  for (int i = 1; i <= n; i++) {
    int ok = 1;
    for (int j = 0; j < cur; j++) if (a[j] == i) ok = 0;  /* 已用过 */
    if (ok) { a[cur] = i; dfs(cur + 1); }
  }
}

7.1 · ENUMERATE

简单枚举：把可能的都试一遍

枚举就是「把所有候选都检查一遍」。关键是选对枚举对象，让候选数量可控。

例题（原创重述）：abc 与它的重排

找出所有满足 abc * 3 = bca 的三位数（a 非 0）。最直接的办法：枚举 a、b、c（各 1~9 / 0~9），检查等式是否成立。候选只有 $9 \times 10 \times 10 = 900$ 个，瞬间跑完。

程序 7-2 · 枚举三位数C++
for (int a = 1; a <= 9; a++)
  for (int b = 0; b <= 9; b++)
    for (int c = 0; c <= 9; c++) {
      int abc = a * 100 + b * 10 + c;
      int bca = b * 100 + c * 10 + a;
      if (abc * 3 == bca) cout << abc << endl;
    }

枚举的原则：① 别漏（候选覆盖所有可能）；② 别重（每个候选只算一次）；③ 能减就减（缩小枚举范围、提前判断，就是「剪枝」）。

换一个枚举对象往往更省：与其枚举 a、b、c 再验证，不如直接枚举 n 从 100 到 999，再拆位检查——有时候「枚举答案」比「枚举输入」快得多。

7.2 · PERMUTATION

枚举排列：n 个元素排一排

全排列用递归生成；C++ 还提供 next_permutation 一键跳到下一个字典序排列。

1. next_permutation

程序 7-3 · 输出所有排列C++
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
  int a[] = {1, 2, 3};
  do {
    for (int i = 0; i < 3; i++) cout << a[i] << " ";
    cout << endl;
  } while (next_permutation(a, a + 3));   /* 生成全部 6 个排列 */
  return 0;
}

注意：next_permutation 会改变数组，且要求数组初始是有序的（最小排列），这样才能遍历全部。

7.3 · SUBSET

子集生成：二进制法

n 个元素的子集有 $2^n$ 个。用二进制数表示子集，是竞赛里最优雅的写法。

1. 位表示子集

集合 {0, 1, 2} 的子集可以用 3 位二进制表示：第 i 位是 1 表示包含元素 i。比如 101 表示 {0, 2}。从 0 枚举到 $2^n-1$ 就枚举了所有子集。

程序 7-4 · 二进制枚举子集C++
int n = 3;
for (int mask = 0; mask < (1 << n); mask++) {   /* 0..7 */
  cout << "{ ";
  for (int i = 0; i < n; i++)
    if (mask & (1 << i)) cout << i << " ";   /* 第 i 位是 1 */
  cout << "}" << endl;
}

7.4 · BACKTRACK

回溯法：八皇后

八皇后是回溯法的标准模板：一行一行放皇后，放不下就「撤销」换一列。

1. 回溯模板

程序 7-5 · n 皇后C++
int col[20], n, ans = 0;
bool ok(int r, int c) {
  for (int i = 0; i < r; i++)
    if (col[i] == c || abs(col[i] - c) == r - i) return false;  /* 同列或对角线 */
  return true;
}
void dfs(int r) {
  if (r == n) { ans++; return; }
  for (int c = 0; c < n; c++)
    if (ok(r, c)) { col[r] = c; dfs(r + 1); col[r] = -1; }  /* 尝试 + 撤销 */
}

核心只有三行：尝试 → 递归 → 撤销（col[r] = -1）。「撤销」让同一层的其他选择互不影响，这就是回溯。

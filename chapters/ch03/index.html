3.1 · ARRAY

一维数组：把一堆数据存起来

循环解决「重复」，数组解决「记住」。数组就是一排连续编号的盒子。

1. 声明与下标

声明 int a[100]; 表示申请 100 个 int 盒子，编号（下标）是 0 到 99。没有 a[100]——这是最容易越界的地方。

程序 3-2 · 读 n 个数，输出最大值C
int a[100], n, i, max;
scanf("%d", &n);
for (i = 0; i < n; i++) scanf("%d", &a[i]);

max = a[0];                      /* 先假设第一个最大 */
for (i = 1; i < n; i++)
  if (a[i] > max) max = a[i];    /* 发现更大的就更新 */
printf("%d\n", max);

这个「先定一个初值，再逐个比较更新」的模式叫扫描/维护最值，后面会反复出现。

3.2 · STRING

字符数组与字符串

字符串在 C 里就是「以 \\0 结尾的字符数组」。理解这一点，字符串问题就变成数组问题。

1. 字符串 = 字符数组 + \\0

char s[100] = "abc"; 实际存了 4 个字符：a b c \0。最后的 \0（空字符）是字符串的结束标记，strlen 数到它就停。声明时要留够空间：char s[100] 最多存 99 个字符。

程序 3-3 · 判断回文C
#include <stdio.h>
#include <string.h>

int main() {
  char s[100];
  int i, len;
  scanf("%s", s);          /* 注意：数组名不用加 & */
  len = strlen(s);
  for (i = 0; i < len / 2; i++)
    if (s[i] != s[len - 1 - i]) {
      printf("NO\n");
      return 0;
    }
  printf("YES\n");
  return 0;
}

三个常见误区：① scanf("%s") 读字符串时数组名前面不写 &；② 它遇到空格/换行就停，读不了「hello world」整行；③ strcmp 比较字符串是否相等，不要用 ==（那是在比地址）。

3.3 · CONTEST

竞赛题目选讲：数一数谁最多

用一道经典题把「数组 + 循环 + 条件」串起来。题目为原创重述。

例题（原创重述）：出现次数最多的数字

给你一个整数 n 和 n 个在 0~9 之间的数字，问哪个数字出现次数最多（并列时输出较小的那个）。

思路：开一个大小为 10 的计数器数组 cnt[10]，读到数字 x 就让 cnt[x]++，最后扫一遍 cnt 找最大值。这是「用数组做计数器」的经典套路。

程序 3-4 · 数字频率统计C
#include <stdio.h>

int main() {
  int n, i, x;
  int cnt[10] = {0};        /* 全部初始化为 0 */
  scanf("%d", &n);
  for (i = 0; i < n; i++) {
    scanf("%d", &x);
    cnt[x]++;
  }
  int best = 0;             /* 找出现最多的数字 */
  for (i = 1; i < 10; i++)
    if (cnt[i] > cnt[best]) best = i;
  printf("%d\n", best);
  return 0;
}

注意 int cnt[10] = {0}; 会把整个数组清零——数组初始化的常用写法。并列时输出较小的，所以更新条件用严格大于 > 而不是 >=。

数字 x 的范围只有 0~9，正好可以当下标：cnt[0] 记 0 出现几次，cnt[1] 记 1 出现几次……读到数字 3 就让 cnt[3]++。数组在这里就是「10 个计数器」。

3.4 · OJ

黑盒测试与在线评测系统

明白 OJ 怎么「打分数」，你才知道比赛里真正要练什么。

1. 黑盒测试

OJ 不会看你的代码写得好不好看，它只做一件事：喂输入 → 跑你的程序 → 比对输出。你的输出和标准答案逐字符相同（包括空格、换行、大小写）才算对。

⌨常见返回状态

AC 通过 · WA 答案错 · TLE 超时 · MLE 内存超限 · RE 运行时错误 · CE 编译错误。

⚙做题流程

读题 → 想思路 → 写代码 → 本地测试样例 → 提交 → 看状态 → 错了就调试重交。

2. 精确输出的三条铁律

① 输出最后一行要不要换行：题目说「每行一个」就换行，说「输出 xxx」看样例。
② 空格位置：多一个空格、少一个空格都是 WA，先和样例逐字符对。
③ 多组数据：题目没说「只有一组」，就用第2章学的 while(scanf(...)==N) 框架。

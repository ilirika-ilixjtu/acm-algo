void merge_sort(int l, int r) {
  if (l >= r) return;
  int m = (l + r) / 2;
  merge_sort(l, m);      /* 分：排左半 */
  merge_sort(m + 1, r);  /* 分：排右半 */

}

8.1 · ANALYSIS

算法分析初步：先算账再动手

大 O 表示法是竞赛的「通用语言」：一句话告诉别人你的算法多快。

1. 常见复杂度从小到大

O$O(1)$

常数时间：下标访问、直接算公式。

O$O(\log n)$

二分查找、平衡树操作，n=10⁹ 也飞快。

O$O(n)$

一次遍历，n=10⁶~10⁷ 没问题。

O$O(n \log n)$

排序、归并、堆，n=10⁶ 没问题。

O$O(n^2)$

双重循环，n=10⁴ 就到 10⁸，危险。

O$O(2^n)$、$O(n!)$

指数级，n=20 就到极限，只用于小数据或剪枝。

估算口诀：评测机一秒约 $10^8$ 次简单操作。把你的复杂度代入数据范围，算出约多少操作，超过 $10^8$ 就要优化。

8.2 · DIVIDE

分治法与归并排序

分治 = 把大问题拆成几个小问题，分别解决，再合并答案。归并排序是它的招牌例子。

1. 归并排序

程序 8-2 · 归并排序（完整）C++
#include <iostream>
using namespace std;
int a[100005], t[100005];

void merge(int l, int m, int r) {   /* 合并两个有序段 */
  int i = l, j = m + 1, k = l;
  while (i <= m && j <= r) t[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
  while (i <= m) t[k++] = a[i++];
  while (j <= r) t[k++] = a[j++];
  for (i = l; i <= r; i++) a[i] = t[i];
}
void msort(int l, int r) {
  if (l >= r) return;
  int m = (l + r) / 2;
  msort(l, m); msort(m + 1, r);
  merge(l, m, r);
}

复杂度：每层合并总共 $O(n)$，一共 $\log n$ 层，合计 $O(n \log n)$——比冒泡/选择的 $O(n^2)$ 快得多。

int l = 0, r = n - 1, ans = -1;
while (l <= r) {
  int mid = (l + r) / 2;
  if (a[mid] == x) { ans = mid; break; }
  if (a[mid] < x) l = mid + 1;   /* 目标在右半 */
  else            r = mid - 1;   /* 目标在左半 */
}

8.4 · GREEDY

贪心法：每步取当前最优

贪心不回头：每一步都选「看起来最好」的，希望最终全局最优。关键是证明「这样选不会后悔」。

1. 三个经典例子

①区间调度

选最多的互不重叠区间：按结束时间排序，每次选结束最早的。

②部分背包

物品可切分：按单位重量价值从大到小拿。

③Huffman 编码

每次合并频率最小的两个节点，得到最优前缀码。

!贪心的边界

0-1 背包（物品不可切分）不能用简单贪心——那是第9章动态规划的事。

程序 8-4 · 区间调度骨架C++
struct Seg { int l, r; };
bool cmp(Seg a, Seg b) { return a.r < b.r; }   /* 按结束时间排序 */
sort(seg, seg + n, cmp);
int cnt = 0, last = -1e9;
for (int i = 0; i < n; i++)
  if (seg[i].l >= last) { cnt++; last = seg[i].r; }   /* 不重叠就选 */

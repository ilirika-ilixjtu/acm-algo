6.1 · STACK & QUEUE

栈与队列：两种「排队规则」

栈像叠盘子（后放先取），队列像排队买饭（先来先服务）。C++ 的 STL 里都有现成的。

1. 栈：后进先出 LIFO

程序 6-2 · 栈的基本操作C++
#include <iostream>
#include <stack>
using namespace std;

int main() {
  stack<int> s;
  s.push(1); s.push(2); s.push(3);  /* 压栈 */
  cout << s.top() << endl;           /* 3，只看栈顶 */
  s.pop();                          /* 弹出 3 */
  cout << s.size() << endl;         /* 2 */
  return 0;
}

6.2 · LINKED LIST

链表：用数组模拟「指针」

竞赛里链表一般不用 new，而是用数组存「下一个节点的下标」，快且好调试。

1. 数组模拟链表

每个节点存两个信息：数据 data[i]，以及「下一个节点是谁」next[i]。遍历时从 head 开始，一路顺着 next 走。

程序 6-4 · 数组链表：输出整条链C++
#include <iostream>
using namespace std;

int main() {
  int data[5] = {3, 7, 1, 9, 4};
  int nxt[5]  = {1, 2, 3, 4, -1};   /* -1 表示链尾 */
  int head = 0;
  for (int i = head; i != -1; i = nxt[i])
    cout << data[i] << " ";          /* 3 7 1 9 4 */
  cout << endl;
  return 0;
}

想删除某个节点，只要让它的前驱跳过它：nxt[prev] = nxt[del]——不需要搬动数据，这就是链表的优势。

数组 vs 链表：数组按下标 $O(1)$ 随机访问，但中间插入/删除要搬元素；链表插入/删除只需改指针，却要 $O(n)$ 找位置。理解「读多写少用数组，改多则用链表」。

6.4 · GRAPH

图：DFS 与 BFS

图是任意两点之间都可以有边的结构。遍历图有两种方式：能走多深走多深（DFS），逐层扩散（BFS）。

1. DFS：求连通块

程序 6-6 · DFS 统计连通块C++
void dfs(int u) {
  vis[u] = 1;
  for (int v : g[u])
    if (!vis[v]) dfs(v);
}
int cnt = 0;
for (int i = 1; i <= n; i++)
  if (!vis[i]) { cnt++; dfs(i); }   /* 每个起点 = 一个连通块 */

2. BFS：求无权图最短路

程序 6-7 · BFS 最短距离C++
queue<int> q;
memset(d, -1, sizeof(d));      /* -1 表示没访问过 */
d[s] = 0; q.push(s);
while (!q.empty()) {
  int u = q.front(); q.pop();
  for (int v : g[u])
    if (d[v] == -1) {
      d[v] = d[u] + 1;
      q.push(v);
    }
}

BFS 用队列逐层扩展，所以第一次到达某个点时走的就是最短路径——这是「BFS 求最短路」的核心原理。DFS 用递归或栈，适合枚举路径、求连通块。

小测｜BFS 原理BFS

为什么 BFS 能求无权图最短路？

拓扑排序把有向无环图（DAG）的节点排成一行，使得每条边都「从前往后」。做法：不断取出「入度为 0」的节点。典型应用：课程先修顺序、编译依赖。第11章还会用到。

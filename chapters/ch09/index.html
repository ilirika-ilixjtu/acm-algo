9.1 · TRIANGLE

数字三角形：DP 的第一课

从顶到底走，每一步只能走到正下方或右下方，求路径数字之和最大。这是理解「状态」最好的例题。

1. 状态与转移

定义 dp[i][j] = 从第 i 行第 j 列走到最底部的最大路径和。那么它只能由下一行的两个位置转移而来：

$dp[i][j] = a[i][j] + \max(dp[i+1][j],\ dp[i+1][j+1])$

从最后一行向上推（从底向上填表），最终答案就是 dp[0][0]。初值：最后一行 dp[n-1][j] = a[n-1][j]。

9.2 · DAG

DAG 上的动态规划

很多 DP 都可以看成「在有向无环图（DAG）上走」：状态是节点，转移是边，答案是某条最长路/最短路。

1. 模型转换

把「数字三角形」画成图：每个格子是一个节点，能走的下一步是边。求最大路径和 = 求 DAG 上的最长路。第11章讲最短路时，很多算法本质也是在 DAG 上做 DP。

程序 9-2 · 记忆化搜索求最长路C++
int f(int u) {                 /* 从 u 出发的最长路 */
  if (dp[u] != -1) return dp[u];  /* 算过就直接返回 */
  int best = 0;
  for (int v : g[u]) best = max(best, f(v) + w[u][v]);
  return dp[u] = best;         /* 记住结果 */
}

这比「从底向上填表」更直观，尤其适合不知道先算哪个状态的题目。代价是递归栈，深度大时要小心。

记忆化 = 递归 + 查表。第一次算完存进 dp，之后再遇到同一个状态直接取。这是把指数级搜索变成多项式 DP 的关键。

9.3 · KNAPSACK

0-1 背包：选 or 不选

容量有限的背包，每件物品最多拿一次，怎么装价值最大？这是最经典的「多阶段决策」DP。

1. 状态与转移

定义 dp[i][j] = 考虑前 i 件物品、容量为 j 时的最大价值。对第 i 件（重量 w、价值 v）：不选就是 dp[i-1][j]；选就是 dp[i-1][j-w] + v，取较大者。

$dp[i][j] = \max(dp[i-1][j],\ dp[i-1][j-w_i] + v_i)$
程序 9-3 · 0-1 背包（一维优化）C++
for (int i = 1; i <= n; i++)
  for (int j = W; j >= w[i]; j--)       /* 容量从大到小！ */
    dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

一维写法里容量必须从大到小遍历：这样每个物品只会被用一次（避免同一件物品被重复拿）。

9.4 · MODELS

更多经典模型

数字三角形和背包是最常用的两个模型；它们的变体几乎覆盖了入门 DP 的全部。

1. 常见模型一览

①线性 DP

在序列上做：最长上升子序列（LIS）、最大子段和。dp[i] 以第 i 个结尾。

②区间 DP

在区间上做：合并石子。dp[i][j] 表示区间 [i,j] 的最优值。

③树上 DP

在树上做：dp[u] 表示以 u 为根的子树的最优值，由子树转移。

④数位 / 状态压缩

进阶模型，先了解名字，遇到再学。

程序 9-4 · 最大子段和（线性 DP）C++
int best = a[0], cur = a[0];
for (int i = 1; i < n; i++) {
  cur = max(a[i], cur + a[i]);  /* 重新开始 或 接上前一段 */
  best = max(best, cur);
}

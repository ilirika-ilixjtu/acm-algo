10.1 · NUMBER THEORY

数论初步：gcd 与筛法

数论是「整数的学问」。两个最常用的工具：最大公约数与素数筛。

1. 欧几里德算法

程序 10-2 · gcd 与 lcmC++
#include <bits/stdc++.h>
using namespace std;

int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }

int main() {
  int a = 12, b = 18;
  int g = gcd(a, b);
  cout << g << endl;                          /* 6 */
  cout << a / g * b << endl;                 /* lcm = 36 */
  return 0;
}

唯一分解定理：每个整数都能唯一写成素数幂的乘积。它告诉我们 gcd / lcm 的本质就是「取指数的最小/最大值」。

2. 埃氏筛

程序 10-3 · 筛出 1~n 的素数C++
vector<bool> is_prime(n + 1, true);
is_prime[0] = is_prime[1] = false;
for (int i = 2; i * i <= n; i++)
  if (is_prime[i])
    for (int j = i * i; j <= n; j += i)   /* 从 i*i 开始标记 */
      is_prime[j] = false;

10.2 · POWER

快速幂与取模

算 $a^n$ 不用乘 n 次：把指数拆成二进制，$O(\log n)$ 搞定。

1. 快速幂

$3^{13} = 3^{1101_2} = 3^8 \cdot 3^4 \cdot 3^1$。把指数看成二进制，只看哪些位是 1，把对应的幂乘起来。代码用「底数平方、指数右移」实现：

程序 10-4 · 快速幂取模C++
long long qpow(long long a, long long n, long long mod) {
  long long res = 1;
  while (n) {
    if (n & 1) res = res * a % mod;   /* 当前位是 1 就乘上 */
    a = a * a % mod;                  /* 底数平方 */
    n >>= 1;                         /* 指数右移一位 */
  }
  return res;
}

2. 取模的注意事项

① 大数相乘先取模再相乘：(a % M) * (b % M) % M，用 long long 防中间溢出。
② C++ 负数取模结果是负数：-5 % 3 = -2，要转正写 ((x % M) + M) % M。
③ 常见的模数：1e9+7（质数，适合做逆元）、998244353（NTT 常用）。

10.3 · COUNTING

计数与概率：杨辉三角

组合数 $C(n,k)$ 是计数的基石，杨辉三角就是组合数的表格。

1. 杨辉三角 = 组合数表

$C(n,k) = C(n-1,k-1) + C(n-1,k)$，边界 $C(n,0)=C(n,n)=1$
程序 10-5 · 递推求组合数C++
long long C[35][35];
for (int i = 0; i <= n; i++) {
  C[i][0] = C[i][i] = 1;
  for (int j = 1; j < i; j++)
    C[i][j] = C[i - 1][j - 1] + C[i - 1][j];
}

离散概率：某事件的概率 = 有利情况数 ÷ 总情况数。组合数就是数「有利情况」最常用的工具。

10.4 · EXPECTATION

递推与数学期望

很多概率题最终化成递推；期望则常配合「线性期望」简化计算。

1. 数学期望

随机变量 X 的期望 $E(X) = \sum x_i \cdot P(x_i)$。关键性质：期望的线性性——$E(X+Y)=E(X)+E(Y)$，不管 X、Y 是否独立。这常把「复杂期望」拆成「简单期望之和」。

程序 10-6 · 掷骰子期望C++
// 掷一枚均匀骰子，点数的期望
double e = 0;
for (int i = 1; i <= 6; i++) e += i * (1.0 / 6);
cout << e << endl;   // 3.5

2. 递推的例子

错排问题（概念）：n 封信全部装错信封的方案数 $D_n = (n-1)(D_{n-1}+D_{n-2})$，$D_1=0,D_2=1$。很多计数题都是「先想递推式，再填表」。

小规模问题通常能靠枚举或手算验证；一旦找到「第 n 项怎么由前面的项推出」，就能用循环填表。所以做题流程常是：小数据打表 → 找规律 → 写递推 → 验证。

int ch[N][26], cnt[N], tot = 1;
void insert(char *s) {
  int u = 1, len = strlen(s);
  for (int i = 0; i < len; i++) {
    int c = s[i] - 'a';
    if (!ch[u][c]) ch[u][c] = ++tot;  /* 开新节点 */
    u = ch[u][c];
  }
  cnt[u]++;   /* 这个单词的结尾 +1 */
}

12.1 · AUTOMATON

自动机与 Trie

字符串算法的高级形态都建立在 Trie 和自动机思想上：一个字符一个字符地「走状态」。

1. Trie：字典树

Trie 把一组字符串按字符分层存成一棵树：根为空，每条边一个字符。插入「acm」「ac」「icpc」时，相同前缀共用节点。查询前缀、统计单词出现次数都很快。

程序 12-2 · Trie 查询前缀C++
int query(char *s) {        /* 返回 s 作为前缀出现了多少次 */
  int u = 1, len = strlen(s);
  for (int i = 0; i < len; i++) {
    int c = s[i] - 'a';
    if (!ch[u][c]) return 0;
    u = ch[u][c];
  }
  return sum[u];            /* sum 记录经过该节点的次数 */
}

12.2 · TREE

树的经典问题

树是「没有环的图」。树上的问题套路清晰，是高级算法的最佳练习场。

1. 四个经典问题

①LCA

最近公共祖先：倍增 / Tarjan / 树链剖分，$O(\log n)$ 查询。

②树的直径

最长路径：两次 DFS/BFS 即可，$O(n)$。

③树的重心

删掉后剩余连通块尽量小；DP 一次求出。

④树形 DP

dp[u] 由子树的 dp 转移，如「没有上司的舞会」。

程序 12-3 · 树的直径（两次 DFS）C++
void dfs(int u, int fa) {
  for (int v : g[u]) if (v != fa) { dep[v] = dep[u] + 1; dfs(v, u); }
}
dfs(1, 0);                /* 第一次：找最远的点 A */
int A = max_element(dep + 1, dep + n + 1) - dep;
dfs(A, 0);                /* 第二次：从 A 找最远点 B */
int diameter = *max_element(dep + 1, dep + n + 1);

12.3 · PERSISTENT

可持久化数据结构

「后悔药」版数据结构：每次修改都留一个版本，随时能回看历史。

1. 可持久化线段树（主席树）

普通线段树修改会覆盖旧值；可持久化线段树每次修改新建一条路径上的节点，旧版本完整保留。用途：静态区间第 k 小、历史版本查询。

①为什么能保留

每次更新只动 $O(\log n)$ 个节点，新建这些节点即可，总空间 $O(n \log n)$。

②典型应用

主席树：在值域上建可持久化线段树，支持「区间 [l,r] 第 k 小」。

程序 12-4 · 可持久化线段树插入（概念骨架）C++
int update(int pre, int l, int r, int pos) {
  int now = ++tot;              /* 新节点 */
  lc[now] = lc[pre]; rc[now] = rc[pre]; sum[now] = sum[pre] + 1;
  if (l != r) {
    int m = (l + r) / 2;
    if (pos <= m) lc[now] = update(lc[pre], l, m, pos);   /* 只新建一边 */
    else          rc[now] = update(rc[pre], m + 1, r, pos);
  }
  return now;
}

12.4 · HARD

难题选解：五类思路

难题不是「想不出来」，而是「没往对的方向想」。记住每类的第一反应。

五类难题的第一反应

①数据结构题

看到「区间、第 k、出现次数」→ 想线段树、树状数组、主席树。

②网络流题

看到「分配、匹配、最大/最小」→ 尝试建模成最大流 / 费用流。

③数学题

看到「大数、取模、计数」→ 想数论、组合、矩阵快速幂。

④几何题

先写几何模板库：点、线、圆、凸包、半平面交。

⑤非完美算法

数据太大没精确解 → 随机化、爬山、模拟退火，尽量多拿分。

⑥杂题

先小数据打表找规律，再猜结论、验证结论。

① 先扫一遍所有题，标记难度；② 从简单的开始 AC，保证基础分；③ 卡住 30 分钟就换题，别恋战；④ 赛后一定要补题（看题解 + 重写），进步全在补题里。

11.1 · MST

最小生成树：Kruskal

n 个城市要连成网，怎样总造价最低？答案就是最小生成树（MST）。

1. 并查集 + Kruskal

程序 11-2 · KruskalC++
struct Edge { int u, v, w; };
bool cmp(Edge a, Edge b) { return a.w < b.w; }
int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }

sort(edges, edges + m, cmp);   /* 按权值排序 */
for (auto e : edges) {
  int ru = find(e.u), rv = find(e.v);
  if (ru != rv) {              /* 不成环 */
    p[ru] = rv;                /* 合并集合 */
    ans += e.w; cnt++;
    if (cnt == n - 1) break;   /* 选够 n-1 条 */
  }
}

为什么从小到大贪心是对的：如果某条权最小的边不进 MST，把它加进去一定能找到一条更优或不差的方案——这就是「贪心正确性」的交换论证。

11.2 · SHORTEST

最短路：Dijkstra 与 Floyd

「从 A 到 B 最快怎么走」是图论最经典的模型。正权图用 Dijkstra，全源用 Floyd，负权用 Bellman-Ford。

1. Dijkstra：单源最短路

程序 11-3 · Dijkstra（朴素版）C++
int dist[N]; bool done[N];
memset(dist, 0x3f, sizeof(dist));   /* 大数表示无穷 */
dist[s] = 0;
for (int k = 0; k < n; k++) {
  int u = -1;
  for (int i = 1; i <= n; i++)
    if (!done[i] && (u == -1 || dist[i] < dist[u])) u = i;  /* 找最小 */
  done[u] = true;
  for (auto [v, w] : g[u])
    dist[v] = min(dist[v], dist[u] + w);   /* 松弛 */
}

堆优化版把「找最小」换成优先队列，复杂度降到 $O((n+m)\log n)$，是比赛标配。Dijkstra 要求边权非负。

11.3 · FLOW

网络流初步：最大流

水管网络里，从水源到用户最多能送多少水？这就是最大流问题。

1. 基本概念

S建模三要素

源点 s、汇点 t、容量 c(u,v)。每条边有容量上限。

F增广路

从 s 到 t 还能「多送」的路径；反复找增广路并累加流量，直到没有为止。

M最大流 = 最小割

割掉最少的边容量让 s、t 断开，这个值等于最大流——「最大流最小割定理」。

C应用

二分图匹配、任务分配、路径覆盖都可以建模成最大流。

为什么网络流重要：它是很多「看起来完全不像流」的问题的统一模型。入门先记住概念和模板（Dinic），会用即可；理论细节放到以后深入。

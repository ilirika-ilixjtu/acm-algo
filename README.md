# 算法竞赛入门 · 交互式学习

把《算法竞赛入门经典（第2版）》的知识体系，做成**原创讲解 + 交互式学习**的静态网站：每段代码都看得见执行过程，每章都有预诊断、小测、可视化与配套刷题清单，目标是打 ACM。

## 站点结构

- `index.html` — 首页：学习路线、章节地图、刷题平台指引
- `chapters/ch01/index.html` — 第1章《程序设计入门》交互课（样板课）
- `assets/css/lesson.css` — 共享课堂样式（莫兰迪纸感 + 明暗双主题）
- `assets/js/lesson.js` — 共享交互逻辑（计时、进度、测验、导出、重置）
- `assets/js/ch01.js` — 第1章配置与交互演示

## 新增章节流程

1. 复制 `chapters/ch01/` 为 `chapters/chXX/`
2. 复用 `lesson.css` / `lesson.js`，按模板重写内容
3. 新建 `chXX.js` 存放配置（localStorage 键、测验解释、导出字段）与专属交互
4. 在首页 `index.html` 的章节地图登记
5. 提交并推送到 GitHub，Pages 自动更新

## 内容说明

本站讲解与示例代码均为原创编写，知识体系参考《算法竞赛入门经典（第2版）》刘汝佳 著（清华大学出版社）。为尊重版权，本站不复制原书正文与例题原文。
